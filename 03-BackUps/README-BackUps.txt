BACKUPS E INSTANTÁNEAS

Durante el desarrollo del proyecto se utilizaron instantáneas de VirtualBox como puntos de restauración del laboratorio.

Estas instantáneas permitieron conservar estados estables antes y después de fases importantes, como:

- Acceso inicial al panel web de Apache CloudStack.
- Configuración de NFS.
- Configuración del bridge cloudbr0.
- Adición del anfitrión KVM.
- Verificación de la infraestructura base.
- Recuperación de KVM y máquinas virtuales de sistema.

Además de las capturas de las instantáneas, se proporciona un enlace externo a Google Drive con una exportación .OVA de la máquina virtual Ubuntu Server utilizada en el laboratorio.
